Privacy

This is a launch-stage privacy page. Before public commercial launch, replace it with a final policy reviewed for the countries and services you operate in.

Camera and microphone

Camera and microphone access is requested by the browser for the booth experience. Browser permissions remain under the user's control.

Temporary memories

Temporary memory links are designed to expire after 10 minutes. The current implementation keeps them in server memory and removes expired entries.

Local Memory Vault

The current browser-based Memory Vault stores saved photos locally on the user's device.

Future cloud accounts

If permanent account-based cloud storage is introduced, this policy should be updated before launch of that feature.
